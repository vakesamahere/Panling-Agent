# 玩家手册（player 子 agent 必读，主 agent 维护）

每次开工先读完本文件。NOTES.md 是地图百科，需要时 grep 查，不要整篇读。
遇到本手册没写的卡点：按「卡住怎么办」处理，并把经验**追加**到本文件末尾「新经验」。

## 1. 三个命令就够了（不要自己写轮询循环）
- `scripts/st.sh` → 一行状态：位置/hp/food/面包/金粒/箭/战斗。
- `scripts/go.sh 地点名` 或 `scripts/go.sh x y z` → 自动寻路（含传送阵），阻塞到结束（最长10分钟），打印一行结果 `ok/reason/pos/last`。
- 其余操作：JS 写进文件再 `scripts/q.sh -f /tmp/x.js | head -c 800`。
- **中文绝不能直接写在 `scripts/q.sh '...'` 里**（会乱码，存进记忆的地点名会坏掉）。有中文一律用 -f 文件。

## 2. 已知地点（`scripts/go.sh 名字` 直接可用）
人族村：村長、小仁、補給品簡方、雜貨舖收購員、鐵匠舖、丹藥舖、傭兵團長、進村點、村莊大門
皇城：皇城中转站、皇城中转站西门外、皇城路口、李公公、皇城東門
东边：龍鬚鎮、王卯
跨地图时 go.sh 会自己走传送阵（村莊大門→皇城中转站；中转站→村；奈何桥→村）。

## 3. 生存规则（上一次差点饿死，必须遵守）
- **免费食物**：`scripts/go.sh 補給品簡方`，然后跑 `/tmp` 里写：走到 (1601.5,140,109.8)，`bot.activateBlock(bot.blockAt(new Vec3(1601,140,108)))`（按钮「領取補給品」）→ 得到 60 面包+元素。一个时辰（约1小时现实时间）领一次。领过了会提示，别反复按。
- 出远门（离开村子/皇城）前：面包 ≥ 20。不够先去领/买。
- 雜貨舖掌櫃(villager 在 ~1631,136,100)：交易 4 = 5金粒→面包12（钱少，优先免费补给）。
- bot 会自动吃（food<14），你只要保证背包有吃的。
- **没吃的又远离村子**：吃包里的「劇毒-鶴頂丹」自杀（会扣等级，但死后在奈何桥满血满饱食），再 `scripts/go.sh 補給品簡方` 回村。鶴頂丹只有一颗，用掉就没了，尽量别走到这一步。
- 奈何桥 (205,54,-1753) 是「抹除存在」= 删号，**绝对不能踩**（go.sh 已禁用它）。

## 4. 主线进度（截至 2026-10-28）
1. ✅ 村長 → 《村長擔憂的事情》
2. ✅ 村莊大門 → 皇城 → 李公公：换得《李公公的委託》+ 皇城地圖
3. ⬜ 去龍鬚鎮找鎮長-王卯（597,45,37）。路线：`scripts/go.sh 皇城東門` → `scripts/go.sh 龍鬚鎮` → `scripts/go.sh 王卯`。路牌：東門(314,45,63)「往東方龍鱗之森 龍鬚鎮」；(506,41,76)「歡迎來到龍鬚鎮」；(487,55,125)「往森林入口」，(475,52,109)「往森林深處」。
4. 和 NPC 对话：必须 ≤2 格，`const w=await bot.openVillager(e)`，读 w.trades 每项输入/输出物品的名字和 lore，有书就是任务交接；换完 `w.close()`。交易 `await h.trade(e.id, idx)`。读书 `h.book(item)`。

## 5. 卡住怎么办（按顺序，别重复同一招超过 2 次）
1. go.sh 报 `no-progress`：看 `pos`。换一个更近的中间点（比如沿路牌方向 20-40 格的坐标）再 go。
2. 中间点也不行：用 `scripts/go.sh` 先退回最近的已知地点，换方向。
3. 不知道路/NPC 在哪：**别靠到处乱走找**。查存档：
   - `node tools/cmdsigns.js x0 x1 z0 z1 | grep SIGN | grep -E '关键字'` → 区域内所有告示牌文字（路牌！）
   - `node tools/cmdblocks.js x0 x1 z0 z1 | grep -E 'summon Villager.*名字|tp @p'` → NPC 生成坐标、传送阵目的地
   - 范围别太大（每次 ≤ 600×600），输出 `| head -40`。
4. 同一目标卡 10 分钟：在最终报告里写清楚卡在哪、试过什么，然后去做下一个目标。

## 6. 战斗
`h.combat.start()` 开自动射箭（只打敌对怪，NPC/守卫已排除）；`h.combat.state()` 看 kills/shots。野外赶路时开着。

## 7. Token 纪律
输出都 `| head -c 800`；不要重复读文件；go.sh 已经帮你轮询了，不要 sleep 循环。
